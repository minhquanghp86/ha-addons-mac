## 2. Chức năng đã chốt
| Trang | Đường dẫn | Dành cho | Nội dung |
|---|---|---|---|
| Khách | `IP:8900` (qua Cloudflare) | khách | đăng nhập (user/pass trong Options) → cắm ESP32 vào **máy họ** → `esptool-js` đọc MAC eFuse ngay trong trình duyệt → điền tên/đơn → gửi |
| Quản trị | **Sidebar HA** (ingress) | chủ | danh sách MAC, **tìm kiếm**, **thêm**, **xoá**, **tải CSV** |

- Dữ liệu: `/data/macs.jsonl` (trong container). Mỗi lần khách gửi → ghi file + gửi **Telegram** (nếu cấu hình).
- `/list`, `/export.csv`, `/api/*` **chỉ mở qua ingress**; truy cập trực tiếp cổng 8900 → **403**.
- Rate limit nội bộ: login **10/10 phút/IP**, toàn site **120/phút/IP** (nhận IP thật qua `CF-Connecting-IP`).

## 3. Lỗi đã gặp & cách sửa (quan trọng khi build lại)
| Lỗi | Nguyên nhân | Fix |
|---|---|---|
| `base name (${BUILD_FROM}) should not be blank` | Supervisor không truyền `BUILD_FROM` | đặt **default trong `ARG`**: `ARG BUILD_FROM=ghcr.io/home-assistant/amd64-base:3.20` |
| `s6-overlay-suexec: fatal: can only run as pid 1` | base image có `ENTRYPOINT ["/init"]`, Supervisor chạy container bằng **`--init`** (tini = PID 1) | **`ENTRYPOINT []`** + `CMD ["python3","-u","/app.py"]` |
| Add-on không lên sidebar | thiếu ingress | `ingress: true`, `ingress_port: 8900`, `panel_icon`, `panel_title` |
| Trang `/list` trắng | CSS `width:100%` bị `%`-format | escape `100%%` hoặc không dùng `%`-format |
| Trang khách vẫn thấy danh sách | link + route mở | gỡ link, chặn `/list`,`/export.csv`,`/api/*` ngoài ingress |

## 4. Việc còn mở
- [ ] **Cloudflare**: public hostname + Rate limiting + WAF (xem `README`/hướng dẫn trước).
- [ ] **Telegram**: đã test `ok=True, message_id=288`; nếu chưa nhận tin, kiểm tra đã **/start** bot và `chat_id` đúng.
- [ ] **Dữ liệu test (17 bản ghi giả)** đang nằm trong `/data/macs.jsonl` của container — xoá trước khi dùng thật.
- [ ] Add-on hiện **đã tắt** (theo yêu cầu). `state: error` chỉ vì đã stop.
- [ ] Frontend `esptool-js` tải từ **unpkg (CDN)** — muốn chạy offline thì bundle file JS vào add-on.

## 5. Lưu ý bảo mật
- PAT dùng trong phiên đã **xoá/bỏ**; repo giờ **public**, không cần token để cài.
- Token Telegram + mật khẩu add-on nằm trong **Options** của add-on (trên máy HA), **không** nằm trong repo.
- Trang khách mở ra internet: nên bật **Cloudflare Access** hoặc rate-limit chặt.
